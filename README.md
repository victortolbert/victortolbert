## Where the work is

**[uxlab.tools](https://uxlab.tools)** — a content-first digital garden, grown in
the open: a tech registry with what each thing is *for*, a glossary that pins
down the vocabulary (component contract, reference site, estate), working labs
(a design-tokens transformer, an icon-collection setting that treats a Font
Awesome Pro license as a preference rather than a rewrite), and guides.

What I'm on right now: measuring an enterprise AEM estate for migration to
Edge Delivery Services, and writing the contracts — patterns, tokens, anatomy —
that a block and an AEM component can each be realized from.

That site's repository is private (it holds working notes). Pieces get
extracted here as they stand on their own; the icon-collection adapter and the
tech cross-linker are first.
